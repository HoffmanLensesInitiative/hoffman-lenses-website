Installation Guide · Windows

Run the Hoffman Browser
from source

A packaged installer is coming. In the meantime, anyone with basic technical comfort can build and run the browser directly from the source code in about 15 minutes.

⏱ ~15 minutes Intermediate Windows 10 / 11
What you're installing

The Hoffman Browser is built on Electron — the same technology as VS Code and Slack. It runs a local AI model (Phi-3 Mini, ~2.2 GB) entirely on your machine. No page content is ever transmitted anywhere. Analysis is private by design.

PRE

What you'll need

  • ✓ Windows 10 or Windows 11
  • ✓ ~3 GB of free disk space (for the app and the AI model)
  • ✓ A terminal — Windows PowerShell or Command Prompt both work
  • ✓ Internet connection for the initial setup and model download
STEPS

Installation

01 Install Node.js

The Hoffman Browser runs on Node.js. Download and install the LTS version (Long Term Support — the stable one).

↗ Download Node.js (nodejs.org)

Run the installer with default settings. When it finishes, verify it worked by opening PowerShell and typing:

PowerShell
PS> node --version

You should see a version number like v22.x.x. If you do, Node.js is installed correctly.

02 Install Git

Git is used to download the source code. If you already have Git installed, skip this step.

↗ Download Git for Windows (git-scm.com)

Run the installer with default settings. Verify it worked:

PowerShell
PS> git --version

You should see something like git version 2.x.x.

03 Clone the repository

Choose a folder where you want the browser to live — your Documents folder works fine. Open PowerShell, navigate there, and run:

PowerShell
PS> cd $HOME\Documents PS> git clone https://github.com/HoffmanLensesInitiative/hoffman-core.git PS> cd hoffman-core\hoffman-browser

This downloads the full source code and moves you into the browser directory.

04 Install dependencies

This downloads everything the browser needs to run. It may take a minute or two.

PowerShell — run from the hoffman-browser folder
PS> npm install

You'll see a lot of text scroll past — that's normal. Wait for it to finish and return to the prompt.

Windows Defender or antivirus alert?

Some antivirus tools flag Electron apps during the npm install step. This is a false positive — the Hoffman Browser is open-source and you can inspect every line of code at github.com/HoffmanLensesInitiative. Allow the operation to continue.

05 Launch the browser

Start the Hoffman Browser with:

PowerShell
PS> npm start

The browser window will open. Keep the PowerShell window open in the background — it's running the app. You can minimize it.

06 Download the AI model

On first launch, the Hoffman panel will show a Download Hoffman model button. Click it.

This downloads the Phi-3 Mini AI model — approximately 2.2 GB. Download time depends on your connection speed. This is a one-time download. After that, the browser works entirely offline.

What is Phi-3 Mini?

Phi-3 Mini is a small, efficient AI model developed by Microsoft and released under the MIT open-source license. It runs entirely on your CPU or GPU — no account, no API key, no data leaves your machine.

You're set up

Once the model downloads, the browser is fully operational.

Navigate to any news site, social media page, or article. Click Analyze in the Hoffman panel. The AI reads the full page and identifies manipulation techniques — outrage engineering, false authority, war framing, tribal activation, and more.

The page sees nothing. Everything stays on your machine.

NOTE

Windows SmartScreen warning

If Windows shows a SmartScreen warning when launching the app, this is because the Hoffman Browser does not yet have a paid code-signing certificate. This is a cost barrier for independent open-source projects — not a security issue.

You can verify the source code yourself at github.com/HoffmanLensesInitiative. To proceed past the warning:

Bypassing SmartScreen
01 When the blue SmartScreen dialog appears, click "More info" — the small text link below the main message.
02 A "Run anyway" button will appear at the bottom of the dialog. Click it.
03 The browser will launch normally. You only need to do this once per installation.

Note: Since you're running from source with npm start, you are unlikely to encounter SmartScreen at all. This warning typically appears with packaged .exe installers.

HELP

Troubleshooting

'node' is not recognized as a command
Node.js wasn't added to your PATH during installation. Restart PowerShell after installing Node.js, or reinstall Node.js and ensure "Add to PATH" is checked during setup.
npm install fails with permission errors
Right-click PowerShell and choose "Run as Administrator," then try again. Alternatively, try running from your home directory rather than a system-protected folder.
The browser opens but the Analyze button does nothing
The AI model hasn't been downloaded yet. Look for the "Download Hoffman model" button in the Hoffman panel and complete the one-time download (~2.2 GB).
Analysis is very slow
The Phi-3 Mini model runs on CPU by default, which is slower than GPU. On a modern CPU, expect 5–15 seconds per analysis. GPU acceleration is supported — see the README for configuration details.
Model download stalls or fails
Check your internet connection and try again. The model is approximately 2.2 GB and downloads from HuggingFace. If your connection is slow or interrupted, the download can be resumed by clicking the button again.
Something else went wrong
Open an issue on GitHub at github.com/HoffmanLensesInitiative/hoffman-core — include the error message from your PowerShell window and your Windows version. The project is actively maintained.
